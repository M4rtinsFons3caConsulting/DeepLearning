This metadata_store hosts a varied assortment of metadata about out data:
    - clenaer_logs - refer to the different image treatements made to the images.
    - image_metadata - refers to the original metadata provided for this project, along with a few additional labels.
    - model_results - <TK> to be determined
    - upsample_logs - hosts the json files for the upsampling schema
    - current signature - allows the current set of cleaning routine and upsampling routine to be written to the model specs.  
    - data_checksums - ensures data integrity when extracting from aditional resources.
